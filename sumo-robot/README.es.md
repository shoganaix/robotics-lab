# 🤼 Robot sumo con sistema de succión

[![Español](README.es.md)](#) [![English](README.md)](README.md)

Robot sumo diseñado para **competiciones de sumo robótico**, construido sobre un **chasis 3D propio** y un **sistema de succión al suelo** que aumenta la tracción y la resistencia a ser empujado fuera del dohyō.

## Estado

Terminado — diseño mecánico listo para competición.

## Estructura

```text
sumo-robot/
├── README.md            # Este archivo
├── README.es.md
└── hardware/
    └── Carchasis.max    # Modelo 3D del chasis (fuente 3ds Max)
```

## Descripción

- **Chasis 3D propio** — toda la estructura fue diseñada por mí en **3ds Max** (`hardware/Carchasis.max`)
- **Sistema de succión al suelo** — mejora el agarre en el ring para ofrecer más empuje
- **Distribución de peso optimizada** — centro de gravedad bajo para estabilidad en combate
- **Estructura mecánica robusta** — pensada para orientación de combate autónoma
- **Electrónica de control embebida** — pendiente de documentar junto al montaje

## Hardware

Abre `hardware/Carchasis.max` con Autodesk 3ds Max para editar/exportar el chasis. Las exportaciones STL para impresión 3D y las fotos del montaje se añadirán a esta carpeta.

> El documento de reglamento de la competición usado durante el diseño **no** está incluido en este repositorio (material de terceros).
