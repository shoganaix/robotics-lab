# 🧰 Librerías

**Estado: En montaje**

Componentes y funciones reutilizables desarrollados en mis proyectos de robótica, para compartirlos entre robots en lugar de reescribirlos cada vez.

## Contenido previsto

| Módulo | Descripción |
|---|---|
| **Cinemática inversa** | Solvers de IK para patas de hexápodos y manipuladores |
| **Motor de gait** | Generadores de paso (trípode / ripple) para robots multipatas |
| **Protocolo serie** | Protocolo ligero de comandos entre MCU y app (`W`/`S`, tramas de movimiento) |
| **Utilidades de servo** | Pinado, calibración y utilidades de movimiento suave |

Cada módulo incluirá su propia documentación y ejemplos de uso. *Todavía no hay nada commiteado — las carpetas se irán poblando progresivamente.*
