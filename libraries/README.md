**Status: Scaffolding**

Reusable components and functions developed across my robotics projects, so they can be shared between robots instead of being rewritten each time.

## Planned Library Contents

| Module | Description |
|---|---|
| **Inverse Kinematics** | Leg/arm IK solvers for hexapods and manipulators |
| **Gait engine** | Tripod / ripple gait generators for multi-legged robots |
| **Serial protocol** | Lightweight command protocol between MCU and app (`W`/`S`, movement frames) |
| **Servo helpers** | Pinning, calibration and smooth-motion utilities |

Each module will include its own documentation and usage examples. *Nothing is committed yet — the folders will be populated progressively.*
