# 🚗 Coche con control por puertas lógicas

[![Español](README.es.md)](#) [![English](README.md)](README.md)

Coche teledirigido cuya **dirección se implementa con puertas lógicas digitales** (sin microcontrolador). El chasis y el mecanismo de dirección fueron **modelados por mí en 3D** por completo.

## Descripción

- **Lógica de control por hardware** — la dirección (avance/retroceso/giro) la decide lógica combinacional con puertas
- **Dirección personalizada** — mecanismo de dirección tipo piñón-cremallera, diseñado y modelado por mí
- **Chasis modelado por mí** — bastidor impreso en 3D que integra toda la electrónica
- **Fusión mecánica + electrónica** — la mecánica y el circuito lógico se diseñaron a la vez

## Fotos

Consulta la carpeta `images/` para ver fotografías del coche ensamblado, el mecanismo de dirección y el circuito lógico.

## Cómo empezar

Las piezas 3D de referencia usadas durante el desarrollo pertenecen a un diseño de Thingiverse con licencia **Creative Commons** (dirección piñón-cremallera) y **no están incluidas** en este repositorio — aquí solo se publican las imágenes de mi montaje.
